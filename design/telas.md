# Inventário de telas — QCYBattery

Nenhuma tela é implementada sem protótipo aprovado pelo Lucas. Todo protótipo vai para aprovação com prints claro e escuro em `design/prints/` (um arquivo por estado relevante); sem prints, não se pede aprovação. Status: rascunho, em revisão, aprovada, implementada. Histórico até 2026-11-25 vive no [LogiBattery](https://github.com/LucasStop/LogiBattery) (os `#N` das notas são issues de lá).
